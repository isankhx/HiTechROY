# Настройки

## `config.json` (сервер)

| ключ | по умолчанию | смысл |
|---|---|---|
| `server.http_host/http_port` | `127.0.0.1:8080` | интерфейс оператора; `0.0.0.0` — доступ с других устройств |
| `server.drone_host/drone_port` | `0.0.0.0:7700` | порт для бортов (в `--sim` всегда только 127.0.0.1) |
| `map_file` | `aruco_map.txt` | карта меток в формате `aruco_pose`: `id length x y z rot_z rot_y rot_x` |
| `flight_bounds` | `[-3.6, 3.6, -2.1, 2.1]` | `[x0 x1 y0 y1]`, куда могут залетать **центры** дронов |
| `survey_bounds` | `[-3.75, 3.75, -2.25, 2.25]` | что покрывает тепловизор; тепловая сетка строится в этих границах |
| **separation** | | |
| `drone_radius_m` | 0.28 | радиус дрона с винтами — измерьте |
| `min_gap_m` | 0.5 | зазор между корпусами |
| `position_margin_m` | 0.2 | запас на ошибку позиции пары аппаратов (по 0,1 м); `D = 2R + gap + margin` = 1,26 м |
| `lookahead_m` | 2.5 | сколько пути вперёд защищается от стоящих дронов |
| **link** | | сторож связи (одинаково на борту и сервере) |
| `hold_after_s` / `land_after_s` | 1.5 / 6.0 | без `hb` — зависнуть / сесть |
| `slow_hold_s` / `slow_resume_s` | 1.0 / 0.6 | круговая задержка связи: зависнуть / продолжить |
| **localization** | | |
| `hold_after_s` / `land_after_s` | 2.0 / 10.0 | без меток — зависнуть / сесть |
| **battery** | | |
| `cell_warn_v` / `cell_land_v` | 3.5 / 3.4 | В на элемент: предупреждение / домой и сесть |
| **flight** | | |
| `takeoff_alt_m` | 1.0 | высота первичного подъёма до захвата меток |
| `takeoff_stagger_s` | 2.0 | интервал между взлётами |
| `lock_timeout_s` | 15 | не нашёл метки за это время на `takeoff_alt_m` → подъём до `search_alt_m` и ещё столько же ожидания → посадка |
| `search_alt_m` | 1.6 | высота второй попытки найти метки (в кадре больше меток) |
| `takeoff_retries` | 2 | сколько раз повторить взлёт, если борт его отклонил (PX4 ещё не готов: EKF, проверки арминга) |
| `takeoff_retry_s` | 4 | пауза перед повтором взлёта |
| `speed_mps` | 0.4 | скорость T2/T3 и перелётов |
| `step_m` | 0.5 | длина шага; меньше — точнее дистанция, больше команд |
| `yaw_deg` | 0 | курс всех дронов в полёте (вдоль +X карты) |
| `max_mission_s` | 900 | лимит времени, затем возврат |
| **thermal** | | |
| `alt_m`, `speed_mps` | 2.0, 0.3 | высота и скорость облёта |
| `camera` | Mileseey TR256i | справочно |
| `hfov_deg`, `vfov_deg` | 56, 42 | углы обзора тепловизора по ширине и высоте кадра (TR256i) |
| `rotate_deg`, `flip_h`, `flip_v` | 0, false, false | ориентация кадра: после них верх кадра = нос дрона |
| `overlap` | 0.3 | перекрытие галсов |
| `threshold` | 3.0 | аномалия: теплее фона на столько (°C или единиц `raw`) |
| `min_pixels` | 3 | минимальный размер пятна в пикселях (после прореживания до 64×48) |
| `target_height_m` | 0.0 | плоскость тепловой карты-подложки и начальная (слабая) гипотеза высоты источника. Координаты аномалий от неё почти не зависят — их даёт триангуляция |
| `height_prior_weight` | 0.02 | вес гипотезы `target_height_m` при триангуляции; работает, пока лучи почти параллельны (первые кадры) |
| `max_source_height_m` | 3.0 | выше этого оценка высоты считается ошибкой геометрии и ограничивается |
| `merge_radius_m` | 0.6 | луч проходит ближе этого от аномалии на её высоте — то же наблюдение; две аномалии, чьи триангулированные точки ближе этого, сливаются |
| `confirm_observations` | 2 | наблюдений до подтверждения |
| `max_tilt_deg` | 20 | кадры с большим креном не используются |
| `grid_cell_m` | 0.05 | ячейка тепловой карты |
| `display_range` | `[-2, 10]` | шкала ΔT на карте |
| `detector` | `threshold` | `threshold` / `nn` / `both` — порог и/или ИК-нейросеть |
| `nn_weights`, `nn_conf`, `nn_imgsz`, `nn_range` | `models/thermal.pt`, 0.4, 128, `[-2, 12]` | ИК-нейросеть: веса, порог уверенности, размер входа, шкала ΔT |
| `sim_size` | `[64, 48]` | разрешение тепловизора в симуляторе (TR256i после прореживания) |
| **inspect** | | |
| `cruise_alt_m` / `photo_alt_m` | 1.3 / 1.0 | высота перелёта / съёмки |
| `settle_s` | 2.0 | успокоение перед фото |
| `task_timeout_s` | 90 | не добрался — пропуск (на каждый следующий ракурс — треть) |
| `orbit_points`, `orbit_radius_m`, `orbit_settle_s` | 4, 0.5, 1.0 | облёт участка: ракурсы по кругу, радиус, успокоение |
| `thermal_inspects_if_alone` | true | T1 сам осматривает, если фотодронов нет или они выбыли |
| **yolo** | | |
| `weights` | `models/rgb.pt` | веса; нет файла → детектор отключён (в `--sim` — SIM-детектор) |
| `conf`, `imgsz` | 0.35, 640 | порог и размер входа |
| `ignore_classes` | `["drone"]` | классы, означающие «это дрон, не находка» |
| **drones[]** | | `id` (совпадает с `agent.json`), `name`, `role` (`thermal`/`rgb`), `priority`, `color` |
| **sim** | | стартовые точки, фон, нагретые объекты (`x y dT r cls`) |

Высоты: `thermal.alt_m` (2.0) выше `inspect.cruise_alt_m` (1.3) — это не защита (пролёт над другим запрещён в XY), а чтобы тепловизор видел широкую полосу, а фото было детальным.

### `landing` — точная посадка на свою метку
| Ключ | По умолч. | Смысл |
|---|---|---|
| `snap_m` | 0.35 | первая позиция по меткам ближе этого к центру метки → дом = центр метки (или `drones[].home_marker`) |
| `approach_alt_m` | 0.8 | высота подхода над домом |
| `final_alt_m` | 0.45 | высота второго выравнивания (метки ещё видны) |
| `tolerance_m` | 0.06 | допустимая ошибка XY перед снижением / посадкой |
| `hold_s` | 1.0 | сколько держать ошибку меньше допуска |
| `align_timeout_s` | 10 | не выровнялся за это время → посадка как есть (с предупреждением) |
| `speed_mps` | 0.3 | скорость снижения к дому |

`drones[].home_marker` — ID метки, на которую ставится дрон (необязательно).

### `trees` — ёлки по RGB
| Ключ | По умолч. | Смысл |
|---|---|---|
| `enabled` | true | включить карту ёлок |
| `detector` | `dark` | `dark` — тёмные колючие кроны (без обучения); `yolo` — веса `yolo_weights`; `off` |
| `yolo_weights`, `yolo_conf` | `models/trees.pt`, 0.35 | для `yolo`: классы с `tree`/`ёлк` в имени, `mark`/`infect` в имени = видимые отметины |
| `tree_height_m` | 1.6 | высота ёлок (центр кроны принимается на половине) |
| `min_crown_m`, `max_crown_m` | 0.25, 1.6 | допустимый диаметр кроны |
| `dark_ratio` | 0.45 | пиксель темнее «пол × ratio» — тёмный |
| `min_roughness` | 1.45 | «колючесть» контура (1 = круг); ниже — не ёлка |
| `merge_radius_m` | 0.45 | лучи ближе этого — та же ёлка |
| `confirm_observations` | 3 | наблюдений до подтверждения |
| `link_radius_m` | 0.5 | подтверждённая тепловая аномалия ближе этого к центру ёлки → ёлка заражена |
| `not_tree_classes` | ["heater"] | аномалия, которую YOLO на осмотре назвал этим классом (нагреватели других команд), ёлку не заражает |
| `inspect_healthy`, `healthy_views` | true, 1 | фотографировать ли здоровые ёлки и сколькими ракурсами |
| `fps` | 3 | кадров в секунду на дрон для карты ёлок |
| `min_alt_m`, `max_tilt_deg` | 1.0, 15 | кадры ниже / с большим наклоном не используются |

`rgb_camera.hfov_deg` (90) — запасная модель камеры, если борт не прислал `camera_info`.

### `flight` — взлёт
`search_alt_m` (1.6), `takeoff_retries` (2), `takeoff_retry_s` (4) — см. `lock_timeout_s` выше.

### `operator` — страница ручной разметки `/op`
| Ключ | По умолч. | Смысл |
|---|---|---|
| `password` | `smena-ego` | пароль страницы (заголовок `X-Op-Key` для `/api/op/*`); пустая строка — страница выключена. В записи полёта не сохраняется |

`localization.max_blind_dz_m` (0.5) — без меток оценка высоты сместилась больше этого → посадка сразу (высота PX4 без камеры ненадёжна).

## `board/agent.json` (борт)

| ключ | по умолчанию | смысл |
|---|---|---|
| `id` | `T1` | должен совпадать с `config.json → drones[].id` |
| `server`, `port` | — | адрес ноутбука |
| `camera_topic` | `/main_camera/image_raw/compressed` | топик JPEG-кадров |
| `map_pose_topic`, `markers_topic` | `/aruco_map/pose`, `/aruco_detect/markers` | откуда `map_age` и число меток |
| `map_frame` | `aruco_map` | система координат для `goto` и телеметрии |
| `takeoff_frame` | `body` | система для первичного подъёма |
| `srv_packages` | `["technic.srv","clover.srv"]` | где искать `Navigate`/`GetTelemetry` |
| `rgb_fps`, `telem_hz` | 5, 10 | частоты |
| `hold_after_s`, `land_after_s` | 1.5, 6.0 | сторож связи борта |
| `max_speed` | 1.0 | ограничение скорости любой команды |
| `thermal.driver` | `none` | `tr256i` (= `uvc_split16`) / `mlx_serial` / `serial_csv` / `uvc` |
| `thermal.device` | `auto` | для `tr256i`: `auto` — поиск среди `/dev/video*`; иначе путь |
| `thermal.bin` | 2 | прореживание k×k на борту (TR256i 256×192 → 128×96) |
| `thermal.baud`, `fps`, `width`, `height`, `crop`, `invert`, `init_hex` | | параметры драйвера (см. `thermal_drivers.py`) |

Запуск: `python run_server.py [--sim] [--speed N] [--sim-drones T1,T2] [--http-host 0.0.0.0] [--http-port P] [--drone-port P] [--config файл]`; борт: `python3 agent.py [--check] [--probe-thermal] [--id T2] [--server IP]`.
